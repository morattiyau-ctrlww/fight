# 📸 照片大魔王 · Photo Boss

一个单文件（`index.html`）的**回合制「照片 Boss」小游戏**：上传一张照片，它就会变成你的对手「照片大魔王」，英雄 🦸 与它各 100 点生命，用「上 / 中 / 下」三段式猜拳式对战决出胜负。

> 纯前端：HTML + CSS + JS 全写在 `index.html` 里，**没有任何后端、没有外部依赖、没有网络请求**，双击文件即可开玩（离线也能玩）。照片只通过 `URL.createObjectURL` 留在你自己的浏览器里。

## 🎮 玩法规则

| 阶段 | 说明 |
| --- | --- |
| 你的回合 | 点击 **上 / 中 / 下**（或键盘 `1 / 2 / 3`）选择攻击位置，大魔王**随机**防守一个位置 |
| 判定 | 位置**相同** → 🛡️ **格挡**，0 伤害；位置**不同** → ⚔️ **命中**，15 伤害 |
| 大魔王回合 | 大魔王**随机**攻击一个位置，你点 **上 / 中 / 下** 选择防守位置，判定规则相同 |
| 结束 | 任意一方 HP 归零：显示 **你赢了！/ 你输了！** 与「再来一局」按钮 |
| 其他 | 顶栏可「换照片」「音效开关」，结算面板可「再来一局」「换张照片」 |

## ✨ 动画与演出

- 🗡️ **飞剑 + 刀光**：攻击时剑从攻击者飞向**被攻击的那一段**，附带拖尾刀光（`--tx/--ty/--rot` 由 `getBoundingClientRect` 精确计算）。
- 🛡️ **盾牌**：无论输赢，盾牌都会出现在**防守的那一段**；没能挡住时盾牌变灰、旁边浮出「方向错误 ✗」。
- 💥 **命中**：目标段红光爆闪 + 斩击十字 + 火花四散 + 爆炸光晕 + 受击方震动 + 全屏红闪 + 飘字「命中！」与 `-15`。
- 🔵 **格挡**：目标段蓝光闪烁 + 护盾波纹扩散 + 风扇式震屏 + 飘字「格挡！0 伤害」。
- 📊 **HUD**：血条平滑过渡（低于 50% 转黄、低于 20% 转红并脉动）、回合数、命中/格挡计数、实时中文战斗日志。
- 🎉 **结算**：胜利撒彩纸 + WebAudio 合成凯旋音效，失败为低音下行音效，还有「大魔王蓄力」红光呼吸提示。
- 📱 **响应式**：桌面双栏（竞技场 + 日志/规则），窄屏自动堆叠；支持 `prefers-reduced-motion`。

## 🚀 使用

```bash
# 方式一：直接双击 index.html
open index.html

# 方式二：起个本地静态服务（可选）
python3 -m http.server 8000   # 然后访问 http://localhost:8000
```
