# 📸 照片大魔王 · Photo Boss（极简版）

选一张照片 → 它就成为「大魔王」；你的英雄是一个小小的**全身小人**。
画面里只留这两个角色，**上 / 中 / 下 的选择键就贴在英雄旁边**，需要你操作时才出现，动画播放时自动收起。

* 单文件 `index.html`（HTML + CSS + JS），**无后端、无外部依赖、离线可玩**
* 照片只在浏览器本地处理（`URL.createObjectURL`），不会上传到任何服务器
* 键盘 `1 / 2 / 3` 等于 上 / 中 / 下

## 玩法

| 阶段 | 说明 |
| --- | --- |
| 你的回合 | 点英雄旁边的 **上 / 中 / 下** → 小人**整身冲上去**砍大魔王那一段 |
| 判定 | 位置**相同** → 🛡️ 格挡，0 伤害；位置**不同** → ⚔️ 命中，15 伤害 |
| 大魔王回合 | 大魔王随机攻击一段，你点 **上 / 中 / 下** 举盾防守，规则相同 |
| 结束 | 一方血量归零 → **你赢了！/ 你输了！** + 再来一局 |

## 动画（都是「整身」的）

* **攻击**：小人蹲一下再整身冲上去，剑挥出刀弧（冲刺残影 + 斩击十字 + 火花 + 爆闪 + 「命中！」/「格挡！」飘字 + 伤害数字）
* **受击**：整身被击退、红光爆闪、屏幕红闪
* **防守**：小人滑到那一段、蹲下举盾；盾挡对位置＝蓝光波纹，挡错＝灰盾 +「方向错误」提示
* **大魔王**：出手前红光蓄力，攻击时整张照片俯冲下来；被打中时整张照片抖动 + 泛红
* **选择键**：只在轮到你操作时滑出，动画开始即收起；中间一条小提示写着「选择攻击位置 / 选择防守位置」

## 使用

```bash
open index.html          # 直接打开即可
# 或者： python3 -m http.server 8000  →  http://localhost:8000
```
